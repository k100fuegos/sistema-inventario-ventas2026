# Bienvenid@s
## Sean bienvenidos al sistema web **Gestión de usuarios, ventas y inventario**
Este sistema permite la gestión de diferentes módulos que se pueden llegar a encontrar en un negocio, en este caso seria a la empresa 
denominada **TechnoByte** en la cual se llego a determinar que seria necesario la creación de los módulos siguientes y sus características
para la correcta gestión del negocio:

### - Modulo de gestión de Uusarios:
Este modulo permite gestionar toda la information relacionada con los usuarios, entre los que incluye:  
- Gestión de información de usuarios

- Manejo de niveles de usuarios (root, cajero y bodeguero)

- Registro de acciones en el sistema (Como inicio de sesiones, gestión de productos o de usuarios o realización de ventas)


### - Modulo de gestion de inventario:
Este modulo es el que permitirá gestionar toda la información del inventario, entre sus funcionalidades incluye:  
- Gestión completa (CRUD) de los productos

- Reportes de productos mas vendidos

- Reportes de productos con stock bajo



### - Modulo de gestion de ventas:
Este modulo permitirá gestionar todo lo relacionado con las ventas, entre sus funciones están:  
- Realización de ventas por parte de los usuarios admitidos

- Gestión completa (CRUD) de las ventas registradas

- Reportes de ventas a nivel semanal y mensual


### Tecnologías utilizadas
Este proyecto se trata de un sistema web, por ende, optamos por utilizar el modelo cliente-servidor, el cual consiste en tres capas
fundamentales, las cuales se mencionan a continuación con la tecnología que utilizamos para esa capa:

Capa de Presentación - HTML, CSS, JavaScript  

Capa de negocio - PHP

Capa de datos - MariaDb
